# 07 · 验收标准

约定：✅ 核心必过；➕ 可选增强。执行方式：npm start 后按顺序核对，记录结果。

## 7.1 桌宠表现

- [ ] ✅ 窗口透明置顶、无边框，桌面其余区域可正常点击（穿透）。
- [ ] ✅ 拖拽跟手；快速甩出后有惯性滑行并回正；松手后位置保存，重启恢复。
- [ ] ✅ 待机时会间歇性走动，工作/睡眠时静止。
- [ ] ✅ 打开 IDE 等办公应用后 ≤15s 切换为工作姿势（带光晕/标签）。
- [ ] ✅ 摸头/戳肚子/戳尾巴三区反馈不同（立绘+特效+台词）。
- [ ] ✅ 右键菜单 9 项全部可用；隐藏后可唤回。
- [ ] ✅ 深夜 23:00–6:00 无主动闲聊。
- [ ] ➕ 三连击彩蛋；粒子效果可关闭。

## 7.2 上下文引擎

- [ ] ✅ 断网 + 无 API：事件正常产生，分类符合当前前台应用。
- [ ] ✅ 静态画面不重复产生事件。
- [ ] ✅ 配置合法模型后，事件含 note/suggest；坏 key 自动降级不弹错。
- [ ] ✅ 事件文件为合法 JSONL；超上限自动裁剪。
- [ ] ✅ 数据目录截图 ≤1 张或已关闭。
- [ ] ➕ 设置页「立即理解一次」15s 内给出结果与缩略图。

## 7.3 AI 能力

- [ ] ✅ 问「我刚才在干嘛」返回基于本地记录的时间线（无模型也可）。
- [ ] ✅ 「今日摘要」输出 3–6 条要点，含应用分布与专注时长。
- [ ] ✅ 模型测试连接返回成功/失败与延时。
- [ ] ➕ 有模型时回答质量优于本地版；成本统计可见。

## 7.4 关怀

- [ ] ✅ 连续工作 25min 出现久坐提醒；1h 内不重复。
- [ ] ✅ 23 点后仍在忙出现劝休息，当晚仅一次。
- [ ] ✅ 离开 ≥3min 回来工作出现「你回来啦」。
- [ ] ✅ 任意两次关怀间隔 ≥15min；台词为提醒而非催促。

## 7.5 养成与设置

- [ ] ✅ 养成数据重启不丢；可一键重置。
- [ ] ✅ 设置六区全部可操作并即时生效。
- [ ] ✅ 单实例：双开只唤起已有实例。
- [ ] ➕ 开机自启、每日任务、周签到、成就解锁。

## 7.6 非功能

- [ ] ✅ 常驻 CPU 均值 <5%、内存 <300MB（记录实测值）。
- [ ] ✅ 未配置模型时断网运行，无任何外部请求（可用抓包/防火墙验证）。
- [ ] ✅ API Key 在界面不回显；日志无密钥。
- [ ] ✅ Win10/11 可安装、卸载干净，桌面快捷方式有效。
- [ ] ➕ 多显示器/DPI 下位置不越界。
