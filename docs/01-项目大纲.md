# 01 · 项目大纲

## 1.1 项目定位

「鲸伴 WhalePal」是一款 Windows 桌面 AI 伙伴应用：一条鲸鱼桌宠常驻桌面，可自由走动、被拖拽互动；后台的上下文引擎周期性观察屏幕，理解用户正在做什么，据此切换陪伴状态、主动关怀，并支持「我刚才在干嘛」「今日摘要」等问答。

一句话：MineContext 的「理解」 × 鲸鱼娘的「陪伴」。

## 1.2 愿景

不打扰、不指挥，只是「陪着，并且理解」。她看得见你的专注与摸鱼，在该提醒的时候轻轻说一句，其余时间安静地待在屏幕一角。

## 1.3 目标用户与典型场景

| 用户 | 场景 |
| --- | --- |
| 学生 / 开发者 / 知识工作者 | 长时间面对电脑，希望有陪伴感与适度提醒 |
| 内容创作者 / 自由职业者 | 需要回顾「今天做了什么」、防久坐 |
| 桌宠爱好者 | 喜欢养成、互动、成就收集 |

典型场景：

1. 开机后小鲸出现在右下角，按时间问候。
2. 打开 VS Code 写代码 → 识别为「工作中」→ 切换抱电脑姿势，安静陪伴。
3. 连续专注 25 分钟 → 气泡提醒休息（非催促）。
4. 离开座位，屏幕长时间无变化 → 打盹待机。
5. 回来后重新工作 → 「你回来啦，我在呢」。
6. 深夜 23 点后仍在忙 → 劝休息，每晚仅一次。
7. 摸头 / 戳肚子 / 戳尾巴、三连击、右键投喂等互动。
8. 设置页提问「我刚才在干嘛」→ 基于本地记录回答时间线；生成今日摘要。
9. 养成：好感、饱食度、等级、每日任务、周签到、成就。

## 1.4 范围

### 1.4.1 v1 包含

- 桌宠表现：透明置顶窗口、桌面漫游、拖拽惯性、10 种姿势立绘、分区互动、三连击、右键菜单、台词气泡、粒子特效、隐藏与唤回。
- 上下文理解：周期截屏、感知哈希去重、视觉模型分析（可选）+ 本地启发式回退、事件本地存储、工作状态联动。
- AI 能力：结合上下文的问答、今日摘要、模型配置（OpenAI 兼容）、调用成本统计。
- 主动关怀：久坐提醒、深夜劝休息、回来打招呼。
- 养成：心情 / 好感 / 饱食度 / 等级 / 每日任务 / 周签到 / 成就。
- 系统：设置面板、托盘常驻、开机自启、单实例、Windows 安装包。

### 1.4.2 v1 不包含（后续迭代）

- 语音合成 / 语音对话（预留接口）。
- 95 个 WebM 动画管线（先 PNG 立绘，预留 video 通道）。
- 浏览器插件 / DeepSeek Harness 集成、双形态数据同步。
- 待办提取、周报、深度检索等 MineContext 高级消费能力。
- 云同步、多用户、移动端。
- macOS / Linux 适配（先 Windows 10/11）。

## 1.5 成功标准

1. 未配置任何模型 API 时，全部核心功能可用，除显式模型调用外零外部网络请求。
2. 常驻 CPU 均值 < 5%、内存 < 300MB（含 Electron）。
3. 上下文链路（截屏→状态判定）在 15s 内完成；配置模型后同链路 ≤ 20s（含模型时延）。
4. docs/07 验收清单中「核心必过」项全部勾选。

## 1.6 命名与形象

- 项目名：鲸伴 WhalePal（鲸 = 形象，伴 = 陪伴）。
- 桌宠默认自称「小鲸」，可在设置中修改；默认称呼用户为「主人」，可修改。
- 形象素材计划直接采用 dsh-whale-musume 的鲸鱼娘立绘（M0 完成许可核查与映射）。
