# 08 · 风险与架构决策

## 8.1 风险登记

| 风险 | 概率 | 影响 | 缓解措施 |
| --- | --- | --- | --- |
| 素材许可证不明 | 中 | 高（法律/合规） | M0 逐仓库核查；无许可不复制；NOTICE 署名 |
| 截屏在远程桌面/特殊 GPU 组合失败 | 低 | 中 | 失败重试+静默降级，不依赖截屏也能走窗口标题启发式 |
| 透明窗口点击穿透在不同 Windows 版本行为差异 | 中 | 中 | setIgnoreMouseEvents(forward) 方案；Win10/11 最低版本验证 |
| VLM 成本失控 | 中 | 中 | 默认变化触发+本地模型优先；成本统计；频率上限 |
| 隐私顾虑 | 中 | 高 | 默认零联网、无遥测、截图仅一张/可关、本地存储 |
| Electron 体积/内存 | 高 | 低 | 素材裁剪、懒加载、性能画像 M5 复核 |
| 多显示器/DPI 坐标错乱 | 中 | 低 | display 事件监听、坐标按工作区重算 |
| 需求蔓延 | 高 | 中 | MVP=P0 边界；P1/P2 按里程碑；评审门禁 |

## 8.2 架构决策记录（ADR）

- ADR-001 选 Electron 而非 Tauri：参考项目生态一致，desktopCapturer 与透明置顶窗口内建支持，开发效率优先。
- ADR-002 渲染层用原生 JS 而非 React：v1 桌宠逻辑简单、追求轻量与启动速度；设置页复杂后再评估迁移 electron-vite+React。
- ADR-003 存储用 JSONL 而非 SQLite/ChromaDB：v1 数据量小、零原生依赖；接口层隔离，v2 可平滑替换。
- ADR-004 默认本地启发式、模型可选：隐私与零成本优先；模型仅作增强，失败自动降级。
- ADR-005 直接复用鲸鱼娘立绘素材（用户决定）：M0 先完成许可证核查与署名，无许可的素材不采用。
- ADR-006 状态机为纯函数并与表现层分离：可单测、易二次开发，是鲸鱼娘工程结构带来的核心原则。
