# 11 · 隐私与数据流（硬保证）

> 这个项目非常关乎个人隐私。本文列出**所有会离开本机的数据**、发生时刻与目的地，
> 以及代码级的三道保障。实现对应：`src/main/context/net.js`（唯一出口）、
> `src/main/main.js`（Chromium 联网开关）、`src/main/paths.js`（单文件夹）。

## 11.1 三条硬承诺

1. **所有数据只落在 `<应用目录>/data/`**：配置、事件、摘要、对话、养成、截图、缓存、日志、崩溃转储。
   不写系统图片 / 文档 / AppData（已通过路径重定向 + 空目录残留修复验证）。
2. **不配置模型 Key 时零联网**：整条链路（截屏、去重、基础感知、关怀、日历、问答模板）全部本地完成。
3. **唯一网络出口 = 你填写的那一个模型端点**：任何硬编码到第三方地址的请求都会被
   `net.js` 的 egress guard 拒绝（http 仅允许 localhost 自定义网关）。

## 11.2 什么数据、什么时候、去哪里

| 数据 | 是否会离开本机 | 何时 / 去哪里 |
| --- | --- | --- |
| 屏幕截图（≤1280px JPEG） | **仅两种情况会** | ① 周期理解：画面有变化时才发给**你配置的模型端点**；② 提问含「现在/此刻」时，现场截一张随问题发送 |
| 前台窗口标题 / 进程名 | 随①一起发送 | 只作为分析上下文的一部分；不做单独上传 |
| 无障碍树文本摘录（≤30 条 / 每次 ≤700 字符） | 随①一起发送 | 本机只读、**不是 OCR**、不额外调用任何模型；只在画面有变化时读取；疑似密钥会被剔除；设置 → 上下文 → 「读取界面文本」可整体关闭（`context.uiText`） |
| 事件明细 / 每日摘要 / 对话记录 / 实体记忆 | **永不整体上传** | 只在提问、摘要、主动搭话判断时，**片段性**作为提示词内容进入对模型端点的请求；实体记忆由本地事件现算（不额外落盘） |
| 养成数据 / 配置 / API Key | **永不离开本机** | 只存 `data/`；Key 界面不回显，也不进 git（`data/` 被 gitignore，跟踪数=0） |
| 日志 / Chromium 缓存 / 崩溃转储 | **不上传** | 存放于 `data/logs`、`data/electron`、`data/crash`；已禁用崩溃上报与后台联网 |
| 遥测 / 统计 / 自动更新 | **不存在** | 无任何遥测代码、无自动更新、无崩溃上报 |

### 入站（只有一处，且仅本机回环）

| 端口 | 用途 | 说明 |
| --- | --- | --- |
| `127.0.0.1:8787`（可关/可改） | 接收 DSH 桥接插件推送的 agent 状态 | **只绑定 127.0.0.1**，绝不监听 0.0.0.0 / 局域网；只接受 POST JSON，请求体上限 8KB，字段全部重新校验并截断；不落盘、不转发给云端。对应插件 `dsh-whalepal-bridge` 也只允许向回环地址发送（`normalizeEndpoint()` 拒绝其它任何主机）。关掉设置里的「DSH 桥接」即完全不监听。 |

## 11.3 三道代码级保障

1. **唯一出口白名单**（`src/main/context/net.js`）：
   `guardedFetch()` 校验目标 URL —— 必须是当前配置 Base URL 的 https 同源同前缀路径，
   或 localhost 的 http；否则抛 `egress blocked`，请求根本不会发出。
   全仓库 `fetch(` 只允许出现在 `net.js` 一处（可用下方命令审计）。
2. **Chromium 后台联网关闭**（`src/main/main.js`，启动即生效）：
   `disable-background-networking`、`disable-component-update`、`disable-domain-reliability`、
   `disable-sync`、`no-pings`、`disable-breakpad`、`disable-crash-reporter`。
3. **单文件夹路径重定向**（`src/main/paths.js`）：
   userData / sessionData / crashDumps / logs 全部指向 `data/`，卸载=删文件夹。

## 11.4 如何自行验证

```powershell
# ① 审计唯一出口：除 net.js 外不应有 fetch 调用
rg -n "fetch\(" src/

# ② 零联网验证：不填 Key，断网运行，全功能可用（基础感知 / 关怀 / 日历 / 模板问答）

# ③ 防火墙验证：给 WhalePal 进程断外网，只有「配置端点」相关调用会失败，其余功能正常

# ④ 落盘验证：运行一段时间后检查
Get-ChildItem "$env:APPDATA", "$env:LOCALAPPDATA" -Directory | Where-Object Name -match 'whale'
Get-ChildItem .\data -Recurse -Depth 1
```

## 11.5 保留策略与清空

| 数据 | 保留 |
| --- | --- |
| 事件明细 | 上限 5000 条（`data/events.jsonl`） |
| 每日摘要 | 每天一条（`data/summaries.jsonl`） |
| 对话记忆 | 上限 400 条（`data/dialogue.jsonl`） |
| 截图 | 仅 `screenshots/latest.jpg` 一张，可在设置里关闭 |
| 无障碍文本 | 不单独落盘；仅作为 `detail / entities / topics` 字段写入当条事件（随「清空上下文记录」一并删除） |
| 跨天实体记忆 | 不单独落盘：每次由 `events.jsonl` 现算，清空记录后自然归零 |

设置 → 数据 → 「清空上下文记录」会同时清空事件 / 摘要 / 对话三层。

## 11.6 与 MineContext 的对照

| 维度 | MineContext | WhalePal |
| --- | --- | --- |
| 数据落盘 | 应用数据目录（本地优先） | 应用目录 `data/`（单文件夹，可整体拷走） |
| 模型 | 支持本地模型 / 云端 | 仅云端（按用户要求），但未配置=零联网 |
| 出网控制 | 本地优先策略 + 自定义端点 | **唯一出口白名单**（代码级拒绝非配置端点） |
| 后台联网 | 未特别说明 | 关闭 Chromium 后台联网 / 组件更新 / 崩溃上报 |
| 截图保留 | 重复帧淘汰 | 只保留最新一张（可关） |
