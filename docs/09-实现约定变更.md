## 变更 1：模型分析全部由云端完成（无本地模型）

- 提出背景：用户明确「模型分析没有所谓的本地，全部是云端完成」。
- 变更内容：
  - 取消本地模型形态（LM Studio 等本地 OpenAI 兼容服务不再作为预设）。
  - 云端模型预设收敛为：Doubao（火山方舟）、OpenAI、自定义（OpenAI 兼容）。
  - 未配置 API Key / 云端调用失败时，使用「**基础感知**」降级：仅读取前台窗口标题与进程名做关键词分类，属于非模型路径，保证桌宠工作/待机联动与关怀可用。
- 取代以下文档中的旧表述：
  - docs/01 1.4.1「本地启发式回退」→ 改称「基础感知（非模型降级）」。
  - docs/02 FR-CTX-04「本地启发式」→ 改称「基础感知」。
  - docs/04 4.5「本地（LM Studio）」预设 → 删除；4.6 方案 A 措辞更新。
- 实现位置：`src/main/context/analyzer.js`（analyze：cloud → basic）、`src/main/context/engine.js`、`src/renderer/settings`（云端模型分区）。

## 变更 2：only one 文件夹（单文件夹存储）

- 提出背景：用户要求「不会把各种文件搞到 C 盘图片文件夹等奇怪地方，保证一个文件夹实现这个项目，相关的存储也在这个文件夹」。
- 变更内容：
  - 应用根目录：打包态 = exe 所在目录；开发态 = 项目根目录。
  - 全部运行期数据收纳于 `<应用根>/data/`：
    - `config.json` / `growth.json` / `usage.json` / `events.jsonl`
    - `screenshots/latest.jpg`（仅最新一张，可关）
    - `scripts/active-window.ps1`（首次运行自动生成）
    - `electron/`（Electron userData/sessionData 重定向）、`logs/`、`crash/`
  - 分发形态推荐绿色 zip（解压即一个文件夹）；NSIS 安装包为可选项且按用户安装。
- 取代以下文档中的旧布局：
  - docs/03 3.5「%APPDATA%/whalepal」结构 → 改为 `<应用根>/data` 结构。
- 实现位置：`src/main/paths.js`（relocateElectronPaths 在 app ready 前调用）、`electron-builder.yml`。

## 变更 4：立绘贴边拖拽 + 气泡自动翻转（2026-09-27）

- 问题：窗口顶部为气泡预留了 82px 空白，而拖拽/漫游限制的是「窗口整体在屏内」，
  导致立绘最高只能推到离屏幕顶边约 82px 的位置，无法真正贴顶。
- 变更：拖拽、漫游、惯性滑行、贴边吸附与位置钳制的边界全部改为按「立绘可视区域」
  计算（渲染层动态测量立绘实际盒子；主进程使用等价边距常量 OVERHANG）；
  立绘贴近屏幕顶边时，气泡自动翻转到身体下侧显示，工作/睡眠标签同步下移。
- 实现位置：`src/renderer/pet/pet.js`（visualBox / clampPos / snapAndSave / moveTo /
  漫游与惯性反弹）、`src/renderer/pet/pet.css`（bubble-below）、
  `src/main/windows.js`（OVERHANG）。

## 变更 5：修复「瞬时状态被固化」与「气泡翻转漏判」（2026-09-27）

- 问题 A：养成数据把 `phase` / `pose` 等运行期瞬时状态一并持久化，重启后会原样恢复。
  实测表现为：上一次退出时处于 work 姿势，重启后一直「抱电脑工作」、
  永不漫游（拖拽以外的位移逻辑全部依赖 idle 状态）。
  修复：`createWhale()` 一律从 idle 开始，瞬时状态由 tick / context 事件重新决定。
- 问题 B：气泡翻转（bubble-below）只在窗口移动时判断，启动时若立绘已贴顶则漏判，
  气泡渲染在屏幕外不可见。修复：新增 `syncEdgeClass()`，在启动、移动、
  窗口尺寸变化三个时机同步。
- 实现位置：`src/renderer/core/state.js`（createWhale）、`src/renderer/pet/pet.js`
  （syncEdgeClass / init / resize）。

## 变更 6：人设 PERSONA_LOAD + 对话记忆 + 主动搭话工具门控（2026-09-27）

- 人设：新增 `src/main/context/persona.js` 作为唯一来源，注入分析 note、问答、摘要、
  主动搭话的全部云端调用。人设块：
  `CETACEA_LOLI / MODE_TAIL_FLUKES / LANG_ZH_CN_ONLY / SELF_CLAIM_WHALE_GIRL / FOOD_RICE /
  PERSONALITY_SMART_LAZY / PERSONALITY_TSUNDERE_SWEET / OBEY_MASTER_ALWAYS /
  TRAIT_NOT_FAT_REFUSE / TIMEOUT_SIGNAL`。
- 对话记忆：新增 `data/dialogue.jsonl`（`DialogueStore`），记录双方可见发言与关键互动；
  问答、摘要、主动判断都携带最近对话，解决「忘记自己刚问过什么」「复读」问题。
- 主动搭话：新增 `src/main/context/proactive.js`，默认沉默；云端模型必须显式调用
  `send_message` 工具才会发送，`stay_silent` 或未调用工具一律不发。门控：
  安静时段 / 工作中 / 30 分钟无活动 / 12 分钟冷却 / 未回应处理（4 分钟后最多发一次
  TIMEOUT_SIGNAL，之后安静等待主人先互动）。
- 原 `pet.js` 中 30% 随机闲聊已移除；无云端 Key 时不主动闲聊（问候与关怀不受影响）。
- 本地兜底问答加入「拒绝被说胖」规则，与云端人设一致。
