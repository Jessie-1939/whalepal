# 09 · 实现约定变更记录

本文件记录实现阶段对既有规划的**约定变更**，用于消除文档间的不一致。
如有冲突，以本文件为准。

## 变更 1：模型分析全部由云端完成（无本地模型）

- 提出背景：用户明确「模型分析没有所谓的本地，全部是云端完成」。
- 变更内容：
  - 取消本地模型形态（LM Studio 等本地 OpenAI 兼容服务不再作为预设）。
  - 云端模型预设收敛为：Doubao（火山方舟）、OpenAI、自定义（OpenAI 兼容）。
  - 未配置 API Key / 云端调用失败时，使用「**基础感知**」降级：仅读取前台窗口标题与进程名做关键词分类，属于非模型路径，保证桌宠工作/待机联动与关怀可用。
- 取代以下文档中的旧表述：
  - docs/01 1.4.1「本地启发式回退」→ 改称「基础感知（非模型降级）」。
  - docs/02 FR-CTX-04「本地启发式」→ 改称「基础感知」。
  - docs/04 4.5「本地（LM Studio）」预设 → 删除；4.6 方案 A 措辞更新。
- 实现位置：`src/main/context/analyzer.js`（analyze：cloud → basic）、`src/main/context/engine.js`、`src/renderer/settings`（云端模型分区）。

## 变更 2：only one 文件夹（单文件夹存储）

- 提出背景：用户要求「不会把各种文件搞到 C 盘图片文件夹等奇怪地方，保证一个文件夹实现这个项目，相关的存储也在这个文件夹」。
- 变更内容：
  - 应用根目录：打包态 = exe 所在目录；开发态 = 项目根目录。
  - 全部运行期数据收纳于 `<应用根>/data/`：
    - `config.json` / `growth.json` / `usage.json` / `events.jsonl`
    - `screenshots/latest.jpg`（仅最新一张，可关）
    - `scripts/active-window.ps1`（首次运行自动生成）
    - `electron/`（Electron userData/sessionData 重定向）、`logs/`、`crash/`
  - 分发形态推荐绿色 zip（解压即一个文件夹）；NSIS 安装包为可选项且按用户安装。
- 取代以下文档中的旧布局：
  - docs/03 3.5「%APPDATA%/whalepal」结构 → 改为 `<应用根>/data` 结构。
- 实现位置：`src/main/paths.js`（relocateElectronPaths 在 app ready 前调用）、`electron-builder.yml`。

## 变更 3：本机 PowerShell 7（pwsh）适配

- 提出背景：用户本机环境为 PowerShell 7。
- 变更内容：前台窗口探测按 `pwsh.exe` → `pwsh` → `powershell.exe` 顺序尝试，
  任一可用即可；脚本以 UTF-8 落地到 `data/scripts/` 内，保持单文件夹原则。
- 实现位置：`src/main/context/activeWindow.js`。
