## 变更 4：立绘贴边拖拽 + 气泡自动翻转（2026-09-27）

- 问题：窗口顶部为气泡预留了 82px 空白，而拖拽/漫游限制的是「窗口整体在屏内」，
  导致立绘最高只能推到离屏幕顶边约 82px 的位置，无法真正贴顶。
- 变更：拖拽、漫游、惯性滑行、贴边吸附与位置钳制的边界全部改为按「立绘可视区域」
  计算（渲染层动态测量立绘实际盒子；主进程使用等价边距常量 OVERHANG）；
  立绘贴近屏幕顶边时，气泡自动翻转到身体下侧显示，工作/睡眠标签同步下移。
- 实现位置：`src/renderer/pet/pet.js`（visualBox / clampPos / snapAndSave / moveTo /
  漫游与惯性反弹）、`src/renderer/pet/pet.css`（bubble-below）、
  `src/main/windows.js`（OVERHANG）。

## 变更 5：修复「瞬时状态被固化」与「气泡翻转漏判」（2026-09-27）

- 问题 A：养成数据把 `phase` / `pose` 等运行期瞬时状态一并持久化，重启后会原样恢复。
  实测表现为：上一次退出时处于 work 姿势，重启后一直「抱电脑工作」、
  永不漫游（拖拽以外的位移逻辑全部依赖 idle 状态）。
  修复：`createWhale()` 一律从 idle 开始，瞬时状态由 tick / context 事件重新决定。
- 问题 B：气泡翻转（bubble-below）只在窗口移动时判断，启动时若立绘已贴顶则漏判，
  气泡渲染在屏幕外不可见。修复：新增 `syncEdgeClass()`，在启动、移动、
  窗口尺寸变化三个时机同步。
- 实现位置：`src/renderer/core/state.js`（createWhale）、`src/renderer/pet/pet.js`
  （syncEdgeClass / init / resize）。

## 变更 9：行为逻辑对齐参考项目——不再乱跑（2026-09-27）

依据 dsh-whale-musume 的实际实现（`reference/dsh-whale-musume/assets/whale-moe-core.js`
与 `dsh-whale-moe.js`）重做桌宠行为：

- **位置恒定**：默认不再自主漫游（`companion.walk` 默认 `false`）。参考项目里她从不自己移动，
  位置只由拖拽决定；设置里勾选「允许在桌面走动」可恢复旧行为。
- **原地待机小动作**：借鉴其 `IDLE_ACTION_POOL`，每 45–110 秒随机播放 4.5–8 秒的日常动作
  （喝咖啡 / 伸懒腰 / 摸鱼 / 晒太阳 / 敷面膜…，素材池 13 张），只换图、不移动窗口。
- **动势换图**：借鉴其 motion-hide swap——旧图快速下压（110ms）→ 在最重的一帧换图 →
  新图弹起（240ms，`cubic-bezier(.34,1.3,.64,1)`）；点击/互动反应保持瞬时切换。
- **AFK 打盹**：3 分钟无互动且主人不在工作 → 原地入睡（`napAfk`），任一互动立即唤醒；
  夜间睡眠不受互动影响（不会被"叫醒"成待机）。
- **基础待机图固定为 `idle-cute`**，不再每次重绘随机跳图；随机性只出现在小动作槽位。

实测：43 秒采样窗口内窗口坐标零变化（不乱跑）；65 秒窗口内原地小动作触发 1 次；
38/38 单元测试通过。

## 变更 11：立绘由屏幕内容决定（确定性映射 + 报错/完成反应）（2026-09-27）

- 此前"工作中"的具体立绘是在同目录内随机挑图（观感上是"花活"）；现在改为**确定性映射**：
  - 新增 `src/renderer/core/pose-map.js`（纯函数，可单测）：work 姿势按
    `category / activity / title` 映射——coding/terminal→`work-debug`、meeting→`work-meeting`、
    design→`work-idea`、部署/发布→`work-deploy`、DDL→`work-deadline`、
    office/reading/writing→`work-review`；同一内容永远同一姿势，类别变化时才换图
    （仍走下压→换图→弹起过渡）。
  - 待机基础图固定 `idle-cute`；小动作按内容偏好选择（video/browsing→摸鱼、
    gaming→打游戏、design→画画、coding/reading→伸懒腰…），并可在设置里整体关闭
    （`companion.idleActions`，默认开启）。
  - 新增屏幕信号：分析结果带 `signal`（none/error/success）。报错 → `failure` 立绘 +
    安慰台词；完成 → `success` 立绘 + 庆祝台词。**同一信号只反应一次 + 2 分钟冷却**，
    不刷屏、不打扰。
- 新增素材：`poses/failure/`、`poses/success/`（取自 dsh-whale-musume，MIT，已署名）。
- 测试：`test/pose-map.test.mjs` 锁定映射规则（coding→debug、meeting→meeting、
  含"部署"关键词→deploy；同一输入同输出；未知类别稳定兜底而非随机）。

## 变更 12：工作姿势改为「语义分组 + 慢节奏轮换」（2026-09-27）

- 问题：上一版"确定性单图"矫枉过正——同一内容永远同一张（用户反馈"一直这样，有点阴间"）。
- 方案：`pose-map.js` 重构为**语义组**：
  coding→[work-debug, work-ram, tool]、terminal→[tool, work-debug, work-ram]、
  deploy→[work-deploy, work-celebrate]、meeting→[work-meeting, work-slack-phone]、
  office→[work-review, work-slack]、reading→[work-review, work-pat]、
  writing→[work-review, work-slack]、design→[work-idea, work-pat]、
  deadline→[work-deadline, work-boss]、other→[work-review, work-boss, work-pat]。
- 轮换节奏：工作组内**每 4 分钟换一格**；待机基础图（idle-cute / greet / curious）
  **每 15 分钟换一格**；内容所属语义组变化时立即换图（仍走下压→换图→弹起过渡）。
- 新素材：work-slack / work-slack-phone / work-ram / work-pat / work-sleep / work-celebrate
  （取自 dsh-whale-musume，MIT，已署名）。
- 测试：`test/pose-map.test.mjs` 更新为组内轮换断言（确定性 + 回环 + 兜底组）。
