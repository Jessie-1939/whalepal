# 05 · 桌宠交互与陪伴设计

## 5.1 状态机

状态：idle（待机）、walk（漫游）、work（工作）、sleep（睡眠）、drag（拖拽）、react（瞬时互动）。

| 事件 | 触发 | 转移 | 动作 |
| --- | --- | --- | --- |
| CONTEXT_WORK | 上下文 isWorking=true | → work | pose=work，停止漫游 |
| CONTEXT_IDLE | isWorking=false | → idle | pose=idle |
| TICK(hour) | 每分钟 | idle↔sleep | 23–6 点且 idle → sleep；白天 sleep → idle |
| DRAG_START | 按住移动>4px | → drag | pose=carried |
| DRAG_END(v) | 松手 | → idle/walk | 惯性滑行、贴边、保存位置 |
| CLICK_HEAD/BELLY/TAIL | 单击 | → react→idle | 立绘+特效+台词 |
| TRIPLE | 1.2s 内 3 击 | → react | celebrate+粒子 |
| FEED/POKE/PRAISE | 右键菜单 | → react | eat/angry/happy |
| CARE(line) | 关怀调度 | 不离开当前态 | 气泡台词 |
| ANSWER(text) | 问答返回 | 不离开当前态 | 气泡台词 |

原则：work/sleep 态不漫游、不闲聊；react 是瞬时态，播放完回落到上一主状态。

## 5.3 拖拽与漫游物理参数

- 点击-拖拽判定阈值：位移 > 4px 才进入拖拽，避免误触。
- 拖拽中：窗口位置 = 光标 − 抓取偏移（相对窗口），body 随水平速度摇摆 ±8°。
- 松手惯性：记录最近 100ms 平均速度 v；|v|>0.25px/frame 时滑行，每帧 v*=0.92，<0.05 停止；滑行结束才保存位置。
- 贴边：松手或滑行时距屏幕边缘 <12px → 吸附到边。
- 漫游：走动 3–8s（速度 30–60px/s，方向每 1.5–3s 做 ±20° 扰动），停顿 4–10s；边界反弹；仅 idle 态进行。

## 5.6 主动关怀规则

| 关怀 | 触发条件 | 冷却 | 示例（原创示意） |
| --- | --- | --- | --- |
| 久坐提醒 | 连续工作 ≥25min | 同类≥60min | 「连续忙了快半小时啦，起来伸个懒腰，喝口水吧～」 |
| 深夜劝休息 | 23:00–6:00 仍在忙 | 每晚 1 次 | 「都这个点了……先休息吧，明天我陪你一起补回来。」 |
| 回来打招呼 | 离开≥3min 后重新开始工作 | 总冷却 15min | 「你回来啦！我一直在呢。」 |

总规则：任意关怀间隔 ≥15min；工作态只允许关怀类台词，不允许闲聊；语气是提醒，不是催促。

## 5.7 台词系统

- 分类：分时问候（早/上午/午/下午/傍晚）、上下文贴题（按 category）、互动回应、关怀、心情分层、等级解锁、摘要开场。
- 数量目标：v1 ≥80 条原创；每类 ≥6 条，避免重复感。
- 深夜 23:00–6:00 不主动说话；工作态不闲聊（关怀除外）。
- 气泡显示时长：闲聊 5s、关怀 6s、回答 12s；自动消失，可打断。

## 5.8 养成数值

| 属性 | 范围 | 来源 |
| --- | --- | --- |
| 心情 | 0–100 | 夸夸+8、摸头+2、戳-5，随时间缓慢回落 |
| 好感 | 0–∞ | 摸头+1、投喂+2、夸夸+2、任务/签到奖励 |
| 饱食度 | 0–100 | 投喂+10，每小时-2 |
| 等级 | Lv1–7 | 按好感阈值（如 0/30/80/160/300/520/800，实现时微调） |
| 陪伴时长 | 累计分钟 | 应用在前台运行 |

每日任务 3 槽（如：摸头一次/问她一个问题/陪伴 30 分钟）每日刷新；周签到 7 格，集满 1/3/7 天给里程碑奖励；成就 ≥8 个（首次摸头、首次投喂、三连击、首问上下文、陪伴 1 小时、连续 3 天签到、深夜关怀、升级 Lv3）。

## 5.9 特效与无障碍

- 粒子：爱心/星星/泡泡，单次 ≤12 个，1.5s 内回收；可整体关闭。
- 无障碍：默认 aria-hidden 纯装饰；可选模式支持 Tab 聚焦、Enter/Space 摸头、方向键微调位置（Shift 加速）。
