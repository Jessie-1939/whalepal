# 04 · 技术选型与集成方案（实现版）

> 云端模型与单文件夹两条硬约定以 docs/09 为准。

## 4.1 技术栈决策

| 领域 | 选择 | 理由 | 备选 |
| --- | --- | --- | --- |
| 桌面框架 | Electron 37 | 参考项目生态一致；desktopCapturer 内建截屏；透明置顶窗口成熟 | Tauri（体积小，但截屏/穿透需更多原生桥接） |
| 渲染层 | 原生 HTML/CSS/JS（无构建链） | 桌宠动画轻量、启动快、易调试；设置页保持原生 | electron-vite + React（后续设置页复杂化再评估） |
| 状态机 | 纯 JS 模块（UMD） | 与表现层分离，node:test 直接测试 | — |
| 存储 | JSONL（事件）+ JSON（配置/养成/用量） | 零原生依赖、可读可审计，全部收纳于 data/ | better-sqlite3（v2 可选） |
| 模型接入 | 云端 OpenAI 兼容 chat/completions | 一套协议覆盖 Doubao / OpenAI / 自定义 | — |
| 前台窗口探测 | PowerShell 7（pwsh）优先，回退 5.1 | 适配用户本机环境；仅读取窗口标题，不外发 | Node 原生模块（避免额外编译依赖） |
| 测试 | node:test | 无额外依赖 | vitest |
| 打包 | electron-builder：zip（推荐）+ NSIS（可选） | zip 解压即单文件夹；NSIS 按用户安装 | — |

## 4.5 云端模型适配细节

- 端点：`{baseUrl}/chat/completions`；图片以 `data:image/jpeg;base64,...` 内联。
- 预设：
  - Doubao（火山方舟）：`https://ark.cn-beijing.volces.com/api/v3`
  - OpenAI：`https://api.openai.com/v1`
  - 自定义：任意 OpenAI 兼容网关
- **本项目不提供本地模型形态**；未填 Key 时使用基础感知（窗口标题分类，非模型）。
- 分析请求要求严格 JSON（`response_format: json_object`），解析时剥代码围栏、
  字段兜底（category 非法 → 关键词分类；isWorking 非布尔 → 按类别推断）。
- 超时 15s、失败即降级；错误摘要写入事件 `cloudError`（最多 200 字符）。
- 提示词包含隐私红线：不复述密码、密钥、金额、证件号、聊天原文。
- 问答/摘要使用文本 chat，附最近 24 条 + 今日至多 40 条精简事件。

## 4.6 成本模型（云端；以当日官方价目为准）

单张截屏（≤1280px）约 800–1100 输入 token。

| 方案 | 频率 | 估算调用/天 | 日成本量级（flash 级 VLM，约 0.8–1.5 元/百万输入 token 时） |
| --- | --- | --- | --- |
| A 基础感知（非模型） | 仅窗口标题 | 0 次 | 0 元 |
| B 变化触发（默认推荐） | 画面变化才调用云端 | 200–400 次 | 约 0.2–0.7 元/天 |
| C 固定周期 | 60s 一次 | 1440 次 | 约 1.2–2.5 元/天 |

设置页展示云端调用次数与失败降级次数（`data/usage.json`），让成本可见、可控；
推荐默认 B（感知哈希去重天然实现），把 C 作为可选档位。

## 4.7 分发与「only one 文件夹」

- 首选 `npm run dist` 产出的 **zip**：解压后即为一个完整应用文件夹，
  运行数据全部在 `<应用目录>/data/`，迁移 = 整个文件夹拷走。
- NSIS 安装包为可选（按用户安装），卸载不残留 data/ 之外的文件；
  安装器与系统启动项（可选开机自启）属于操作系统机制，不含用户数据。
- 注意：不要将应用放在需要管理员权限的目录（如 Program Files），
  否则 data/ 可能不可写——绿色 zip 建议解压到用户可写位置。

## 4.8 PowerShell 7 适配

- 前台窗口探测按 `pwsh.exe` → `pwsh` → `powershell.exe` 顺序尝试；
- 探测脚本首次运行时生成到 `data/scripts/active-window.ps1`（单文件夹原则）；
- 脚本仅调用 user32 的 GetForegroundWindow / GetWindowTextW / GetWindowThreadProcessId，
  不访问网络、不写任何其他位置。
