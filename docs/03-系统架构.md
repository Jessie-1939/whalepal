## 3.3 上下文数据流

1. 定时器触发（默认 60s，可配置 15–3600s；`context.enabled=false` 时暂停）。
2. 截屏：desktopCapturer 取主屏缩略图（≤1280×720），编码 JPEG(q72)。
3. 去重：64 位感知哈希；与上次汉明距离 ≤6 判定无变化，直接跳过（不消耗云端调用）。
4. 分析：
   - 已配置云端 Key：JPEG base64 → `{baseUrl}/chat/completions`（含图片）→ 严格 JSON；
   - 未配置 / 调用失败：基础感知（窗口标题 + 进程名关键词分类），`source=basic`。
5. 落盘：事件写入 `data/events.jsonl`；可选覆盖 `data/screenshots/latest.jpg`。
6. 广播：向所有窗口发送 `context:update`。
7. 消费：桌宠切换工作/待机姿势并可能触发贴题台词；关怀调度评估三条线；
   设置页「当前状态」卡片与对话/摘要读取事件记录。

```json
{
  "ts": 1750000000000,
  "date": "2026-09-27",
  "time": "14:32",
  "activity": "编写代码（Code）",
  "category": "coding",
  "app": "Code",
  "title": "app.py - Visual Studio Code",
  "isWorking": true,
  "note": "看起来进入状态了，键盘敲得很稳。",
  "suggest": "",
  "source": "cloud | basic",
  "cloudError": ""
}
```

category 枚举：coding / office / writing / design / meeting / reading /
video / chat / browsing / gaming / terminal / idle / other。
isWorking=true：coding、office、writing、design、meeting、reading、terminal。

## 3.5 单文件夹数据布局（only one 文件夹）

```
<应用根>/                     # 打包态 = exe 所在目录；开发态 = 项目根目录
└─ data/
   ├─ config.json             # 全部设置（含 API Key，仅存本机、界面不回显）
   ├─ growth.json             # 养成数据（心情/好感/饱食/成就/日记）
   ├─ usage.json              # 云端调用统计（次数/失败/最近来源）
   ├─ events.jsonl            # 上下文事件（超上限自动裁剪）
   ├─ screenshots/latest.jpg  # 仅最新一张（可关）
   ├─ scripts/active-window.ps1
   ├─ electron/               # Electron userData/sessionData（缓存等重定向至此）
   ├─ logs/                   # 应用日志
   └─ crash/                  # 崩溃转储
```

实现要点：`relocateElectronPaths()` 在 `app.whenReady()` 之前调用
（userData / sessionData / crashDumps / logs 四个路径全部重定向到 data/ 内），
确保 Chromium 的缓存也不会散落到 AppData。

## 3.8 错误与降级

- 云端超时（15s）/ HTTP 错误 / JSON 解析失败 → 本次事件以基础感知生成，
  `source=basic` 并记录 `cloudError`，界面不弹错。
- 截屏失败（无屏幕源）→ 本轮跳过，下一轮重试。
- 姿势素材缺失 → emoji 占位，功能不受影响。
- 存储写失败 → 静默忽略并继续（事件内存中仍可用）。
- 前台窗口探测失败（PowerShell 不可用）→ 空标题走基础感知 idle 判定。

## 3.9 安全与隔离

- 渲染进程：`contextIsolation=true`、`nodeIntegration=false`、`sandbox=true`，
  仅通过 preload 暴露的 `whalepal.invoke/on` 白名单通道访问主进程。
- 页面 CSP：`default-src 'self' whalepal:`，脚本仅本地，图片仅本地协议与 data:。
- 资产协议 `whalepal://` 带路径穿越校验；数据目录与素材目录分别挂载。
- API Key 仅保存在 `data/config.json`，界面以 password 输入且不回显；日志不打印密钥。
