# 06 · 开发计划与里程碑

## 6.1 里程碑总览

| 里程碑 | 主题 | 预估 | 交付物 |
| --- | --- | --- | --- |
| M0 | 调研与资产准备 | 0.5–1 人日 | 许可证核查表、立绘映射目录、NOTICE 署名 |
| M1 | 桌宠窗口骨架 | 1–1.5 人日 | 可运行的透明窗口+拖拽+漫游+托盘 |
| M2 | 上下文引擎 | 1.5–2 人日 | 截屏→去重→分析→存储→广播全链路 |
| M3 | 陪伴与互动 | 1.5–2 人日 | 状态机、姿势联动、互动、关怀、台词 |
| M4 | 设置面板与 AI | 1.5–2 人日 | 设置页、模型配置、问答/摘要、养成 |
| M5 | 打磨与交付 | 1 人日 | 性能、降级、打包、验收清单跑通 |

合计约 7–10 人日。

## 6.2 各里程碑任务

### M0 调研与资产准备

- [ ] 克隆 5 个参考仓库到 reference/（不入库）。
- [ ] 逐一读取 LICENSE，产出许可核查表（可用/仅参考/禁止）。
- [ ] 按 4.4 映射表，把可用立绘裁剪到 src/renderer/pet/assets/poses/。
- [ ] 记录交互参数（拖拽/漫游/关怀）为设计常量。
- [ ] 更新 NOTICE 署名；核实模型当日价格，更新成本表。
- DoD：poses 目录齐全，许可表无「未知」项。

### M1 桌宠窗口骨架

- [ ] 透明无边框置顶窗口 + 点击穿透。
- [ ] 自定义资产协议 + 立绘清单扫描。
- [ ] 贴图、懒加载、emoji 兜底。
- [ ] 拖拽 + 惯性 + 贴边 + 位置持久化。
- [ ] 待机漫游（边界反弹）。
- [ ] 托盘：显示/隐藏、设置、退出；单实例锁。
- DoD：拖拽手感达标、重启位置恢复、隐藏可唤回。

### M2 上下文引擎

- [ ] desktopCapturer 截屏（缩略图+JPEG）。
- [ ] 感知哈希去重（单测覆盖）。
- [ ] 前台窗口标题/进程探测脚本。
- [ ] 本地启发式分类（关键词表+分类单测）。
- [ ] VLM 调用 + JSON 稳健解析 + 超时降级。
- [ ] JSONL 事件存储 + 裁剪 + 统计。
- [ ] 事件广播与「立即理解一次」。
- DoD：断网可用；静态画面不重复分析；配置模型后事件带 note。

### M3 陪伴与互动

- [ ] 纯函数状态机（node:test 单测）。
- [ ] 工作/待机/睡眠姿势联动。
- [ ] 分区互动、三连击、右键菜单。
- [ ] 气泡与粒子特效。
- [ ] 关怀调度三条线 + 冷却 + 深夜静默。
- [ ] 台词库 ≥80 条 + 选择器单测。
- DoD：状态机测试通过；互动反馈齐全；关怀不刷屏。

### M4 设置面板与 AI

- [ ] 设置窗口六区 UI（原生 JS）。
- [ ] 模型配置 + 测试连接 + 成本统计。
- [ ] 上下文问答（本地回退 + LLM）。
- [ ] 今日摘要（时间线/专注时长/应用分布）。
- [ ] 养成持久化 + 每日任务/签到/成就 + 重置。
- [ ] 开机自启、打开数据目录、清空记录。
- DoD：全部设置项生效；无模型时问答可用。

### M5 打磨与交付

- [ ] 性能画像（CPU/内存达标）、立绘懒加载。
- [ ] 多显示器/DPI、错误降级路径复查。
- [ ] NSIS 打包、安装/卸载/快捷方式验证。
- [ ] README 使用说明与隐私说明。
- [ ] 跑通 docs/07 验收清单并记录结果。
- DoD：验收清单「核心必过」全绿。

## 6.3 测试策略

- 单元（node:test）：状态机转移、台词选择、感知哈希、分类表。
- IPC 冒烟：无头/临时窗口下跑通 3.7 全通道。
- 手动验收：docs/07 清单。
- 性能基线：Task Manager/进程指标记录，M5 复核。

## 6.4 依赖与风险

- M2 依赖 M1 窗口体系；M3 依赖 M2 事件流；M4 依赖 M2 存储与模型层。
- 关键外部依赖：Electron 下载（网络）、参考仓库可访问性、模型 API 可用性（M4 验证用）。
