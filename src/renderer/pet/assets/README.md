# 桌宠立绘放这里（poses 目录）

把从鲸鱼娘项目（Sutera-Diffusus/dsh-whale-musume）克隆来的立绘，按下面的
姿势目录放进 `assets/poses/<姿势>/`，应用启动时会自动扫描并在对应状态显示；
目录为空时自动使用 emoji 占位，不影响运行。

| 姿势目录 | 使用场景 | 参考素材来源（以仓库实际命名为准） |
| --- | --- | --- |
| `idle/` | 待机 | 待机 / 喝咖啡 / 伸懒腰 |
| `walk/` | 桌面漫游 | 待机系 + 摆动 |
| `work/` | 检测到工作状态 | 抱笔记本工作系 |
| `sleep/` | 深夜 / 离开 | 睡眠系 |
| `happy/` | 夸夸、多击 | 星星眼 / 得意 |
| `shy/` | 摸头 | 脸红系 |
| `eat/` | 投喂 | 吃东西 |
| `celebrate/` | 成就 / 升级 | 升级庆祝 |
| `carried/` | 拖拽中 | 被拎起来 |
| `angry/` | 戳一下 | 生气系 |
| `failure/` | 屏幕出现报错 / 失败 | 沮丧系 |
| `success/` | 屏幕出现完成 / 成功 | 达成系 |

另外可在本目录放一张 `logo.png` 作为托盘图标。

命名不限，支持 `.png` `.webp` `.gif` `.avif`；每个目录可放多张，切换姿势时随机取一张。
